# 数据结构说明

## 1. 当前标准 CSV 结构

当前用户提供的案例库表头为：

```text
车型, 长, 宽, 高, 轴距, 最大功率, 最大扭矩, 续航里程, 电池类型, 快充时间, 价格, LCC（10年）
```

## 2. 字段含义

- `车型`：车辆名称或车型名称
- `长`、`宽`、`高`：车身尺寸
- `轴距`：车辆轴距
- `最大功率`：动力参数
- `最大扭矩`：动力参数
- `续航里程`：续航能力
- `电池类型`：当前为数值编码
- `快充时间`：快充耗时
- `价格`：销售价格
- `LCC（10年）`：当前案例中的 10 年生命周期成本

## 3. 与程序模块的对应关系

### `data_manager.py`
- 直接读取上述中文表头
- 当前估算主流程依赖这些字段完成特征清洗和归一化

### `database.py`
- 已按该 CSV 结构预置字段映射
- 当用户在界面中载入该 CSV 后，程序会将其作为 SQLite 案例库的初始数据导入
- 可将中文列名映射到 SQLite 表字段：

| CSV列名 | SQLite字段 |
|---|---|
| 车型 | model_name |
| 长 | length |
| 宽 | width |
| 高 | height |
| 轴距 | wheelbase |
| 最大功率 | power |
| 最大扭矩 | torque |
| 续航里程 | range_km |
| 电池类型 | battery_type |
| 快充时间 | charge_time |
| 价格 | sale_price |
| LCC（10年） | lcc_total |
