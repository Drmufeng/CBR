# 整理说明

## 1. 为什么做整理

原始版本可用于原型验证，但存在代码集中、目录边界不清、验收口径不统一的问题。  
在现有基础上完成可交付化整理：

## 2. 本次已完成内容

### 2.1 主流程打通

- 已可顺序演示：导入 CSV -> 参数输入 -> 开始估算 -> 模型验证 -> 导出结果。

### 2.2 LCC 分项基础版

- 已提供简化分项：购置成本、使用成本、回收收益、总 LCC。
- 目标是先具备展示与扩展接口
### 2.3 SQLite 基础案例库

- 支持现有 CSV 导入 SQLite。
- 支持基础查询、新增、编辑、删除、清空、导出。
- 支持估算记录与验证记录留痕。

### 2.4 验证与误差分析

- 已补齐平均误差、MAPE、RMSE、最大误差、最小误差。
- 已补齐误差分布统计。
- 支持验证报告导出：Excel（多 sheet）和 CSV（三文件）。

### 2.5 代码组织优化（适度）

- `main.py` 保持轻入口。
- `gui_app.py` 负责主流程。
- `record_windows.py` 承接案例库/验证记录/估算记录子窗口。
- 算法、验证、数据库、LCC 逻辑分别放入对应模块。

## 3. 本次明确未包含

- 稳定网页自动采集系统（仅保留接口与扩展入口）。
- 完整数据库管理后台和复杂案例维护界面。
- CBR 全流程重构、权重自动优化、完整网格搜索实验。
- 论文撰写、答辩讲解、结果指标保证。
