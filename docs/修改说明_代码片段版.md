# 新能源汽车 LCC 估算软件修改说明（代码片段版）

## 1. 说明

- 本文档用于替代“在交付源码中逐行加注释标红”的做法。
- 为保证最终交付代码整洁、可直接运行，`delivery/src` 下源码不再插入大段“修改开始/修改结束”注释。
- 本文档以客户最初原型源码 `3. 软件相关/main.py` 为对照基线，说明当前交付版相较原始版本做了哪些功能扩展，并附对应代码片段。

### 原始版本

- 单文件主程序：`3. 软件相关/main.py`

## 3. 主要修改点

### 3.1 从单文件程序拆分为模块化结构

原始版本所有界面、数据处理、算法和导出逻辑集中在 `3. 软件相关/main.py` 中。交付版拆为多个职责明确的模块，便于维护、继续开发和打包交付。

- 原始版：所有逻辑都放在一个 `main.py`
- 交付版：入口单独保留，核心逻辑拆到 `gui_app.py`、`database.py`、`validation.py` 等文件

### 3.4 增加 LCC 分项展示（购置 / 使用 / 回收）

原始版本界面只显示总 LCC。交付版增加了购置成本、使用成本、回收收益展示，并单独抽出 `LCCCostModel` 模块。

代码片段：`delivery/src/lcc_model.py`

```python
class LCCCostModel:
    def __init__(self, config=None):
        self.config = config or {
            'years': 10,
            'annual_mileage': 15000,
            'electricity_price': 0.7,
            'maintenance_per_year': 2000,
            'insurance_per_year': 4500,
            'residual_rate': 0.2,
        }

    def calculate(self, purchase_price, energy_consumption=None, maintenance_cost=None, insurance_cost=None, residual_rate=None):
        years = self.config['years']
        annual_mileage = self.config['annual_mileage']
        electricity_price = self.config['electricity_price']
        ...
        use_cost = energy_cost + maintenance * years + insurance * years
        recycle_income = purchase_price * residual
        total_lcc = purchase_price + use_cost - recycle_income
```

### 3.5 增加验证指标、误差分布统计和多格式导出

原始版本验证功能较基础。交付版增加了平均误差、MAPE、RMSE、误差分布统计，并支持 Excel 多工作表导出或 CSV 多文件导出。

代码片段：`delivery/src/validation.py`

```python
def build_validation_summary(validation_results, total_count):
    df = pd.DataFrame(validation_results, columns=['车型', '实际LCC', '估计LCC', '相对误差'])
    ...
    mape = df['相对误差'].mean()
    rmse = math.sqrt(((df['估计LCC'] - df['实际LCC']) ** 2).mean())
    return pd.DataFrame(
        {
            '总样本数': [total_count],
            '可评估样本数': [len(df)],
            '最大误差': [df['相对误差'].max()],
            '最小误差': [df['相对误差'].min()],
            '平均误差': [df['相对误差'].mean()],
            'MAPE': [mape],
            'RMSE': [rmse],
        }
    )
```

代码片段：`delivery/src/cbr_experimental.py`

```python
class ExperimentalEstimator:
    @staticmethod
    def estimate(engine, input_data):
        exact_values = engine.processor.find_exact_matches(input_data)
        if exact_values is not None and len(exact_values) > 0:
            return (
                float(np.max(exact_values)),
                [{'车型': '完全匹配车辆', 'LCC（10年）': val, 'similarity': 1.0} for val in exact_values],
                '精确匹配',
                0.0,
            )
        ...
```

说明：

- 交付版保留稳定基线算法
- 同时加入实验算法做对比

## 4. 结论

相较客户最初提供的 `3. 软件相关/main.py`，当前交付版的主要升级可以概括为：

1. 从单文件原型重构为模块化工程结构
2. 从静态 CSV 升级为 SQLite 案例库 + 记录库
3. 增加案例库管理、验证记录、估算记录等工程化界面
4. 增加 LCC 分项展示能力
5. 增加更规范的验证指标与导出报告
6. 增加实验算法与后续网页采集接口预留
