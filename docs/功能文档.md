# 功能文档

## 1. 当前已实现功能

### 1.1 主流程演示
- 支持完整演示路径：导入 CSV -> 参数输入 -> 开始估算 -> 模型验证 -> 导出结果

### 1.2 参数输入与算法选择
- 支持输入车辆参数：长、宽、高、轴距、最大功率、最大扭矩、续航里程、电池类型、快充时间
- 输入框支持鼠标滚轮调整
- 支持 `manhattan`、`cosine`、`experimental_hybrid` 三种算法
- 其中 `experimental_hybrid` 为并行实验算法，不替代现有标准算法

### 1.3 CBR 估算与结果展示
- 基于相似案例检索进行 LCC 估算
- 展示估算值、相对误差、置信度与相似案例列表

### 1.3.1 实验版算法说明
- `experimental_hybrid` 为并行实验算法，不替代现有标准算法
- 当前思路是在现有案例库字段范围内，引入“数值特征相似度 + 电池类型类别匹配”的混合相似度
- 实验版仅用于对比估算效果与后续优化预留，不代表已完成参数级 CBR 重构

### 1.4 LCC 分项计算
- 已接入简化成本分解框架：
  - 购置成本（销售价格）
  - 使用成本（电费、保养维修、保险）
  - 回收收益（残值率）
- 展示总 LCC 与分项结果

### 1.5 模型验证与误差分析
- 基于留一法逐条验证案例
- 展示总样本、可评估样本、阈值内样本占比
- 输出平均误差、MAPE、RMSE、最大误差、最小误差
- 输出误差分布统计（区间样本数与占比）

### 1.6 验证报告导出
- 一键导出验证报告
- 支持 `Excel`（汇总 / 误差分布 / 详细数据）
- 支持 `CSV`（汇总 / 误差分布 / 明细三个文件）

### 1.7 SQLite 案例库管理
- 案例库入库：支持 CSV 导入 SQLite
- 案例查询：支持关键词与排序
- 案例维护：支持新增、编辑、删除、多选删除、清空
- 案例导出：支持导出为 Excel
- 记录字段：`data_source`、`collected_at`、`created_at`、`updated_at`

### 1.8 验证记录与估算记录
- 验证记录：批次汇总 + 批次明细，可查询、导出（Excel/CSV）、删除选中批次、清空全部记录
- 估算记录：估算批次 + 相似案例明细，可查询、导出（Excel/CSV）、删除选中批次、清空全部记录
